## 0. 本ノートの位置づけ

WP-001の二層モデルは「撃った日」から構成されている。本ノートは逆方向、すなわち**撃たなかった日**から二層構造に制約を与えることを試みる。N-003（レートチェック）が「シグナルはあったが実弾がなかった」局面を扱ったのに対し、本ノートは「実弾の好機はあったがシグナルもなかった」局面を扱う。

なお本ノートの中心的な狙いは「なぜ撃たなかったか」の解明ではない。日本当局の非執行理由は、N-003 §3で示した証拠の非対称構造により**恒久的に一次確認不能**である。本ノートが到達しうるのは理由ではなく境界（bound）にとどまる。この限界を先に明示する。

## 1. Question

**RQ-1（事実）**　2026年8月7日に、財務省確定ベースの外国為替平衡操作は存在したか。

**RQ-2（識別）**　存在しなかったとして、それは第一層（発動条件）の消灯によるものか、当局が介入とマクロ環境変化を代替財として扱っているためか、または第二層（執行条件）についての本研究所の理解が誤っているためか。

**RQ-3（本命）**　**介入によって作られた円高と、マクロサプライズによって作られた円高は、減衰速度が異なるか。**

RQ-3を本命とする理由は標本数にある。介入エピソードは n=6 で頭打ちだが、米Tier1指標のサプライズは毎月発生する。RQ-3はWP-001の半減期という構成概念を保ったまま、標本制約を迂回しうる唯一の経路である。

## 3. Method

### 3.1 母集団の事前定義（選択バイアス対策・第22条）

「撃たなかった日」は母集団のほぼ全体である。8月7日を事後に選び出す限り、本ノートは選択サンプルの上に立つ。よって対象集合を先に定義する。

> **NX-POP（非執行観測母集団）**
>
> 2022-09-01以降、次をすべて満たす営業日を対象とする。
>
> (a) 米国Tier1指標の発表日である（雇用統計、消費者物価指数、FOMC声明日の3種に限定）
> (b) 当日のUSD/JPY日足において、高値からの下落幅が **1.50円以上**
> (c) 直近の介入エピソード最終介入日から **60営業日以内** である

条件(c)は「当局が発動判断を保持していた可能性がある期間」に限定する趣旨である。60営業日はWP-001 §8.3の観測項目（30営業日）の倍としたが、独立の根拠を持たない任意の値である。

> **閾値の事後性についての告白（第23条）**
>
> 1.50円という閾値は、2026年8月7日の下落幅1.909円を観測した後に設定されている。したがって**8月7日を含む遡及集計は記述であり、検定ではない**。本定義が事前定義として機能するのは、2026-08-09以降に発生する観測に対してのみである。

### 3.2 半減期の測定（WP-001 §2と同一手続き）

- Impact = 当日高値 − 当日安値（円高方向）
- 半減期閾値 = 安値 + Impact / 2
- 半減期 = 終値ベースで閾値を上抜けるまでの営業日数

**2026-08-07への適用**

```
Impact      = 158.575 − 156.666 = 1.909
半減期閾値  = 156.666 + 0.9545  = 157.6205
当日終値    = 157.805  →  閾値を既に上抜け
半減期      = 0営業日（当日中に到達）
戻し率      = 1.139 / 1.909 = 59.7%
```

同日中に約6割を吐き戻している。E6安値155.226までの距離は1.440円であった。

### 3.3 二仮説の識別設計

| | **H1 便乗仮説** | **H2 代替仮説** |
|---|---|---|
| 前提 | ドル安局面は Impact/Cost を最大化する理想の執行窓（前例：2024-07-11 米CPI下振れ直後） | 介入とマクロ環境変化は代替財である |
| 8/7の解釈 | 理想の窓が開いたのに撃たなかった ⇒ **第一層が消灯していた** | マクロが無償で円高を作った ⇒ **撃つ必要がなかった** |
| 第一層の状態 | OFF | ON（ただし発動不要） |
| 次に撃つ条件 | 水準が発動域（E6起点163円台）へ回帰するまで撃たない | 水準に関わらず、米金利低下が止まり円安が再開した時点で撃ちうる |

両仮説は8/7について同一の観測を生む。分離は将来の観測によるほかない。

> **分離基準（本ノート公開時点で固定）**
>
> USD/JPY終値が **159.483** を上抜ける**前**に新規の円買い介入が観測された場合、**H1を棄却する**。
> 159.483を上抜けた**後**に介入が観測された場合、両仮説と整合するため**識別不能**とする（第58条）。

> **独立性の毀損についての明示**
>
> 159.483はWP-001 §8におけるE6半減期の反証装置として既に固定されている。本ノートがこれを再利用することで、一つの観測がN-005とWP-001の二つの主張を同時に決着させる。検証機会は増えるが、**両者の結果は独立ではない**。この依存関係を結論部で必ず再掲する。

### 3.4 事前登録（PR-003）

> **PR-003**（起案時は PR-002 と仮称したが、PR-002は「円買い介入の資金制約」として2026-08-09に公開・凍結済みのため改番。第19条により公開済み番号は動かさない）
>
> **① 2026-08-07に、財務省確定ベースの外国為替平衡操作（円買い）は存在しない。**
>
> **② 一次判定**：2026-08-28公表の月次実績（対象 2026-07-29〜2026-08-27）。同期間はE6（7/30・7/31・8/3）を含む。E6の報道推計合計は約12.7兆円（6.5＋5.2＋1.0）である。
>
> **③ 確定判定**：2026年11月上旬の四半期日次内訳。

> **8/28では確定しないことの明示**
>
> 月次実績が推計合計を上回った場合、その原因は (a) 8/7の介入 と (b) E6推計の過小 に分離できない。両者の分離は日次内訳の公表を待つ。したがって**8/28で確定するのは「乖離の有無」のみ**であり、PR-003①の判定は11月へ持ち越される可能性が高い。
>
> この乖離そのものはN-001（E6介入額の推計乖離記録）の対象である。**N-005 §3.4とN-001は同一の公表物を共有する。** 重複計上を避けるため、乖離幅の測定はN-001に、8/7の帰属判定はN-005に配分する。

### 3.6 第2事例：速度条件下の執行／非執行（2026-08-11 事前固定）

第1事例（8/7・マクロ起因の円高に対する非執行）と対をなす第2事例として、**円安方向の速度条件が充足された場合の執行／非執行**を観測する。判定基準を結果が出る前の本日（2026-08-11）に固定する。

**判定変数（定義スイッチの禁止）**　OANDA日足**終値**の3営業日累計変化のみを用いる。分足・安値→高値（ヒゲ間）由来の瞬間速度は本判定に用いない（用いる場合は別途事前定義した上で将来観測に限る）。なお「0.94円/24h」等の速度ベンチマークは財務省の公表基準ではなく、WP-001がE5から記述的に推定した当研究所の変数である。

**基準率（正典OANDA・2007-02-01〜2026-08-07・5,068本・当研究所再計算）**　終値3営業日累計 ≥ +3.6円は21件（0.41%）、5営業日 ≥ +6.0円は6件（全て政策レジーム転換または資金繰り危機に対応）、7営業日 ≥ +8.4円は0件（歴代最大 +7.04円・2014-10-28→11-06）。

**観測窓と判定** 起点＝2026-08-07終値157.805円。2026-08-12〜08-14の各営業日終値で「直近3営業日の終値累計変化 ≥ +3.6円」の成立を判定する。
- 成立し、かつ当該期間に円買い介入が観測された場合 → 反応関数（二層）と整合する観測1件として記録
- 成立し、かつ介入が観測されなかった場合 → **速度条件は単独では執行の十分条件でない**ことの観測として記録（本ノート第2事例・成立）
- 8/14終値まで不成立 → 判定不能として閉じ、継続監視に戻す

**含意の上限（第20条）**　いずれの帰結もWP-001の「破綻」を意味しない。WP-001はn=6の記述であり十分条件を主張していないため、本観測が与えるのは反応関数の**適用限界の記述**である。

**タイムスタンプについて**　本§の証明力は公開時刻に依存する。サイト公開版（docs/n-005_obs2_protocol_v1.0.md・SHA-256台帳掲載）の公開をもって固定とし、OTS刻印はGitHub初回push時に付す（§10の順序制約参照）。

## 5. Hypothesis

- **H0**：介入起因の円高とマクロ起因の円高の減衰速度に差はない
- **H1**：便乗仮説（第一層消灯）
- **H2**：代替仮説（介入とマクロは代替財）
- **H3**：第二層モデルの誤り（本研究所の「執行窓」の定義が当局の判断基準と対応していない）

## 6. Alternative Hypotheses（第20条3項）

1. **覆面介入**。8/7の下落1.909円の一部が介入である可能性は、日次内訳の公表まで排除できない
2. **協調上の制約**。RC-4・E6では米側（NY連銀）の関与が確認されている。米指標発表直後に米当局の同意が得られない制度的事情があるなら、日本側の執行窓という枠組み自体が誤りである
3. **主体の誤認**。2026年1月・7月の協調は米財務省主導との報道がある。発動判断の所在が日本側にないなら、第一層の監視対象を誤っている
4. **余力制約**。「撃たなかった」ではなく「撃てなかった」可能性。N-004（残存介入余力・FIMAレポ）の結論と突き合わせる【要照合】
5. **交絡**。月初のフロー、オプション期日、五十日仲値、夏季の流動性低下など、指標発表以外の要因を統制していない

## 8. Limitations

- 1.50円閾値は事後設定である（§3.1）。遡及集計は記述であり検定ではない
- 159.483の二重使用により、N-005とWP-001の結果は独立でない（§3.3）
- 日足のみでは介入の有無を判定できない。分足未取得
- NX-POPは指標3種に限定しており、地政学イベント等による同規模ショックを除外している
- **非執行の理由は日本当局において恒久的に一次確認不能である**（N-003 §3）。本ノートは理由を特定しない。境界を与えるにとどまる
- E6は右打ち切りのまま。本ノートの全結論は暫定である
