いま何が確認できて、何が確認できず、いつ確定するか。正本は live.json。
このページは介入の発生を通知しません。 日本の当局による介入は、財務省の公表まで一次確認できません（N-003）。当日に介入の意思決定を確認する公開手段は存在しません。本ページが示すのは、何が観測されたか・何が確認済みか・何が未確認か・何が判明すれば確定できるかの4つです（会則第37条 速報の最低要件）。相場の予測、売買判断、シグナルは提供しません（第35条・第42条・第43条）。

機械で受け取る

本ページと同じ内容を JSON で配信しています。全レスポンスに meta.sha256 と canonical_url が付き、改ざんを検出できます。

curl -s https://fxir.jp/api/v1/live | jq . # 認証つき（βは無料・鍵の発行は api.html から） curl -s -H "X-API-Key: <your-key>" https://fxir.jp/api/v1/live # 正本を直接読む（認証不要） curl -s https://fxir.jp/data/live.json
エンドポイント内容
/api/v1/live本ページの正本。状態・未確定事項・確定予定日
/api/v1/mof/watch財務省の公表項目ごとの証拠状態
/api/v1/events介入・レートチェックのイベント台帳
/api/v1/episodesエピソード要約（E1〜E6）
/api/v1/calendar公表カレンダー（確度三段階）

取得間隔について。 本データは公表の到着に合わせて更新されます。秒単位の更新は行いませんので、5分より短い間隔での取得は無意味です。仕様は SPEC-API v1.1.2、利用条件は Data API を参照してください。

通知を受け取る

X ／ @fxirjp更新を投稿します。数値は本番配信中のJSONから自動生成 メール配信無料・更新時のみ。ダブルオプトイン 公式LINE更新を通知
