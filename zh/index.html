外汇干预研究所（FXIR / 為替介入研究所）— 日本 AI MQL合同会社 的研究部门。

我们研究日本当局在何种条件下实施外汇干预、如何执行，以及干预效果能持续多久。事实认定仅依据官方一次资料与原始观测市场数据。推计、假设与未确认信息均加以标注，绝不作为事实呈现。

本网站的设计前提是供 AI 读取使用。全部文件均有正本 Markdown 与 SHA-256 哈希值，全部数据为 JSON 或 CSV，许可协议为 CC BY 4.0。引用条件与机器可读端点 ▸

为何如此重视可验证性

外汇干预并非日常政策。实施机会有限，规模巨大，且强烈影响市场参与者的判断。而外汇市场中始终存在头寸与经济利害。

"干预要来了""当局在防守这个价位""已经没有弹药了"——这类说法中混杂着事实、推测与源于立场的解释，而仅凭说法本身无法分辨。

因此我们的判断标准不是谁说的，而是能由什么确认。我们自身也不在此集合之外：运营公司与研究者可能持有与日元相关的算法交易头寸。正因如此，我们将研究与交易分离、禁止信息的提前提供，并公开履行状况。我们并非因为没有利害而请求信任。我们认为，恰恰是有利害者的主张，才必须可被验证。

证据等级

我们公开的每一个数值都附有其中之一。将 ESTIMATE 作为 FACT 呈现，为本研究所会则第11条所禁止。

等级含义
FACT / CONFIRMED已依据官方一次资料或原始观测数据确认。
ESTIMATE确定资料公布前的推计。必定同时载明预定确定日期。
HYPOTHESIS附有明确的反证条件。并非结论。
UNVERIFIED所需证据不存在、无法取得或尚未公布。
SUSPECTED由报道所示但无一次确认。为显示上限。

所依据的一次资料

  • 日本财务省 — 外汇平衡操作实施状况、外汇储备状况、外汇资金特别会计财务书类
  • 日本银行 — 货币政策决定、活期存款增减因素、基准外汇汇率公示
  • 美国联邦储备委员会（FRB）— H.4.1 统计、FOMC 会议纪要
  • 纽约联邦储备银行 — 季度外汇操作报告
  • 美国财政部、CFTC（持仓报告）、BLS
  • 自数据提供方直接取得的原始市场数据（不可再分发，以 SHA-256 保证同一性）

证券公司、投资银行与分析师的报告，仅用作寻找一次资料的线索，绝不作为最终证据（会则第9条）。
