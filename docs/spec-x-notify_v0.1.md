制定: 2026-08-08 ｜ 対象: FXIR Observation Dashboardのデータ更新通知

## 原則
1. **Canonical Event First（第39条）**: 配信はfxir.jpへのデプロイ完走後にのみ発火する（CIの`workflow_run`で構造的に強制）。本文の数値はリポジトリではなく**本番配信中のJSON**から読む。
2. **決定的テンプレのみ（第12条）**: 本文は固定テンプレート＋機械集計値。AIによる文生成・解釈・相場観は載せない。全ツイートに「一次資料の機械集計（解釈なし）」を明記。
3. **禁止表現（第36条）**: 「介入確定」「弾切れ」等の断定・煽動語をテンプレに含めない。
4. **冪等性**: `data/x/posted.json`にストリーム別の最終配信キー（report_date等）を記録し、二重配信しない。
5. **鍵管理**: 4鍵はGitHub Secretsのみ（第61条・コード非収載）。鍵未設定時はDRY RUN。
6. **対象ストリーム（v0.1）**: CFTC週次（金曜取得後）／H.4.1週次（木曜取得後）。イベント状態変化・研究公開の告知は**人間が投稿**する（DATA automatic / INTERPRETATION human）。

## 障害時
取得失敗・API失敗はログのみでリトライしない（次回デプロイ後に自然回復）。連続失敗はstatus.htmlのSTALE検知が拾う。
